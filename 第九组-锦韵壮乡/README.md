# 锦韵壮乡 · 广西壮锦非遗文化数字展馆

25 大数据 2 班　第九组　期末大作业（5 个页面，一人一页）

## 一、怎么打开

双击任意一页文件夹里的 `index1.html` 即可，无需服务器、无需联网。
五页之间已经用相对路径接好导航，点顶部菜单可以互相跳转。

## 二、目录结构（文件夹名已带负责人）

```
第九组-锦韵壮乡/
├── 01-首页-任宏宇/       index1.html  page.js  style.css  assets/
├── 02-文化介绍-黄俊杰/   同上
├── 03-纹样展示-白高领/   同上
├── 04-互动留言-申涛/     同上
├── 05-关于联系-周家豪/   同上
└── README.md
```

每个文件夹都独立可运行，各自带一份 `style.css`、`page.js`、`assets/`，
单独拷走一个也能正常显示。

## 四、学号怎么填

每个 `index1.html` 第一行是一段注释，只有姓名和学号：

```html
<!--
  锦韵壮乡 · 广西壮锦非遗文化数字展馆　第 1 页 / 共 5 页：首页
  姓名：任宏宇
  学号：__________（待填）
-->
```

把自己的学号换到 `学号：` 后面即可，共 5 处（每人一处）。

## 五、响应式断点

- 桌面：≥ 1200px，入口卡四列、纹样四列、成员五列
- 平板：768–1199px，入口卡两列、纹样两列、成员三列，导航仍横排
- 手机：≤ 767px，全部单列，导航折进汉堡菜单，按钮撑满整宽

## 六、引用路径

全部相对引用，没有盘符或绝对路径：

- 本页：`./style.css`、`./page.js`、`./assets/p1.jpg`、`url(./assets/hero.jpg)`
- 跨页：`../02-文化介绍-黄俊杰/index1.html`

## 七、放到 Gitee Pages（可选）

1. 新建仓库，把 `第九组-锦韵壮乡` 整个文件夹推上去；
2. 仓库 → 服务 → Gitee Pages → 部署分支 master，部署目录填 `第九组-锦韵壮乡`；
3. 部署完成后访问生成的地址，入口是 `01-首页-任宏宇/index1.html`。
